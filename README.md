# FIFA World Cup 2026: A Data Science Deep Dive

**HIT140 Foundation of Data Science - Assessment 2 (Group Project Presentation)**
**Charles Darwin University**

## Overview

This repo presents our group's analysis of FIFA World Cup 2026 team and player data, addressing **Objective 1** of the project brief. The team analysis is structured around six distinct analytic tasks:
 
- Analytic question formulation
- Data wrangling
- Data preparation and sampling
- Descriptive statistics
- Inferential statistics (Confidence interval)
- Inferential statistics (either a One-Sample t-Test OR a Two-sample t-Test)
